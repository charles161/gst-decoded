# GST Decoded

An interactive, scroll-driven visual guide to India's Goods & Services Tax (GST), built for founders who want to understand how the system actually works without reading dry tax circulars.

**Live site:** https://charles161.github.io/gst-decoded/

## What's Inside

- **18 chapters** walking from first principles to edge cases:
  1. Why GST Exists
  2. CGST, SGST & IGST
  3. Registration
  4. Rate Structure
  5. Returns Calendar
  6. Input Tax Credit (ITC)
  7. E-Invoicing
  8. E-Way Bills
  9. Composition Scheme
  10. Reverse Charge (RCM)
  11. Payments (Three Wallets)
  12. Annual Compliance
  13. Penalties
  14. Refunds
  15. Assessments & Appeals
  16. Composition vs Regular
  17. Special Situations
  18. The Big Picture
- **Interactive widgets:** Tax Calculator, ITC Supply Chain Visualizer, Three Wallets simulator, Returns Timeline, Penalty Calculator, and Composition vs Regular Decision Tree.

## Tech Stack

- React 19 + TypeScript + Vite 7
- Tailwind CSS 4
- Framer Motion + GSAP + Lenis smooth scrolling

## Local Development

```bash
npm install
npm run dev
```

Build and lint:

```bash
npm run build
npm run lint
```
